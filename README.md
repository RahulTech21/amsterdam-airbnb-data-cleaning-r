# Airbnb Amsterdam: Data Cleaning and Preliminary Analysis in R

Week 1 task for the Virtual R Data Analyst Internship.

## Contents
- amsterdam_airbnb_analysis_v3_fixed.Rmd: R Markdown source (code and explanations)
- The Word report: knitted output with code, results, charts and screenshots

## Data
Inside Airbnb, Amsterdam, detailed file listings.csv.gz
(https://insideairbnb.com/get-the-data/), snapshot dated [your date].
Download it into the same folder as the .Rmd before knitting.

## How to run
1. Install R and RStudio.
2. install.packages(c("tidyverse","janitor","naniar","skimr","corrplot","knitr","rmarkdown"))
3. Open the .Rmd, set the working directory to its folder, and click Knit to Word.
